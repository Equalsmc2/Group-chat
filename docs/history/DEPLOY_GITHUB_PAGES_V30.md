# Deploy Soul Seekers v30 to GitHub Pages

1. Extract `soul-seekers-v30-github-pages-root.zip`.
2. Upload the **contents** directly to the repository root so `index.html` is at the root.
3. Publish the included `firestore.rules` in Firebase Console.
4. Ensure Firebase **Anonymous Authentication** is enabled.
5. Hard-refresh the DM laptop and TV.
6. Confirm the top rail reads **V30**.
7. Normal URL = trusted DM-capable desktop.
8. `?tv=1` = player TV.
