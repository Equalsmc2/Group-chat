# Deploy Soul Seekers v29 to GitHub Pages

1. Extract `soul-seekers-v29-github-pages-root.zip`.
2. Upload the **contents** of the ZIP to the root of your GitHub Pages repository. `index.html` must be at repository root, not one folder deeper.
3. Commit the files.
4. In GitHub: **Settings → Pages → Deploy from branch → main → /(root)**.
5. Complete `FIREBASE_SETUP_V29.md` before expecting DM CONTROL and cross-device writes to work.
6. Hard-refresh the DM laptop and TV after deployment. The top rail should show **V29**.

Normal DM URL:

`https://YOUR-NAME.github.io/YOUR-REPO/`

TV URL:

`https://YOUR-NAME.github.io/YOUR-REPO/?tv=1`

Force the ACT II → ACT III opening for a demo:

`https://YOUR-NAME.github.io/YOUR-REPO/?intro=1`
