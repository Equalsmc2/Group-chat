# Deploying Soul Seekers v33 to GitHub Pages

Use the `soul-seekers-v33-github-pages-root.zip` deliverable.

1. Extract it.
2. Upload the **contents** directly to the root of the `Group-chat` repository so `index.html` is at repository root.
3. Commit changes.
4. GitHub → Settings → Pages → deploy from `main` / root if not already configured.
5. Hard-refresh the hosted site after deployment.

DM URL: `https://YOUR-NAME.github.io/Group-chat/`

TV URL: `https://YOUR-NAME.github.io/Group-chat/?tv=1`

Firebase Anonymous Authentication + the included Firestore rules are required for real cross-device synchronization.
