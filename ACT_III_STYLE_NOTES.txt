SOUL SEEKERS — ACT III / v27

Visual direction
- Permanent dark-mode painterly fantasy UI.
- Red paint cuts, teal/blue counter-accents, warm ivory typography, angular editorial panels.
- Existing Soul Seekers imagery/portraits only; no third-party game artwork is included.
- Veil mode is removed. Act III is the single permanent visual language.

Opening
- Desktop page load plays ACT:2 -> ACT:3, then reveals the new interface.
- Click the transition to skip.
- Reduced-motion users skip automatically.

Performance
- Terminal-only chat/weather/map/ambient systems suspend while Combat is active.
- Music is the intentional exception: the same YouTube player, Firebase music library and visualizer remain live across Terminal and Combat.
- In Combat the existing music card moves into a compact dock, so there is still only one player and one canvas.
- The Act III skin uses primarily CSS shapes and one-shot transitions instead of new continuous animation loops.
