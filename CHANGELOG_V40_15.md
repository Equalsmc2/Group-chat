# Soul Seekers V40.15 — Quick Combat Director

A sixth DM Control workspace for rapid mid-combat edits. Player selection, one-click
damage/healing, custom damage/heal, HP/max/temp HP, condition toggles, death save
counters, concentration, Undo, and the original full editor are all available.
The combat state's existing DM authorization, history, Firestore write queue,
and TV/player updates are reused.

The release uses the cleaned/optimized V40.10 base + V40.14 Dead Air/TV flashcard
fixes. No bulk deletion or Firebase rules changes.
